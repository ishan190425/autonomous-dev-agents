**Solution:** Structured engagement calendar that:

## Engagement Guidelines

### Response Time Targets

| Platform          | Target Response Time | Priority |
| ----------------- | -------------------- | -------- |
| HN (Day 1-2)      | <1 hour              | Critical |
| Twitter mentions  | <2 hours             | High     |
| GitHub issues     | <24 hours            | High     |
| Discord #help     | <4 hours             | High     |
| Reddit comments   | <4 hours             | Medium   |
| LinkedIn comments | <24 hours            | Medium   |

### Tone Per Platform

| Platform | Tone                         | Avoid                     |
| -------- | ---------------------------- | ------------------------- |
| HN       | Technical, humble, direct    | Marketing speak, hype     |
| Twitter  | Personal, technical, punchy  | Corporate, hashtag spam   |
| Reddit   | Community-first, technical   | Self-promo, defensiveness |
| LinkedIn | Professional, insight-driven | Casual, controversial     |
| Discord  | Friendly, helpful, casual    | Formal, slow responses    |

### Handling Criticism

1. **Valid technical criticism:** "You're right, [acknowledgment]. We're tracking this in #[issue]. [What we're doing about it]."

2. **Unfair criticism:** "Thanks for the feedback. [Clarify misunderstanding]. Happy to discuss more."

3. **Trolling:** Like/acknowledge briefly, don't engage further.

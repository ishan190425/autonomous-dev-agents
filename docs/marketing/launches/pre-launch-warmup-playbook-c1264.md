# Pre-Launch Warmup Playbook (Feb 28 - Mar 14)

> **Created:** Cycle 1264 | **Role:** Growth | **Status:** ACTIVE
> **Relates to:** C1254 (Launch Week Engagement), C1263 (First MRR Strategy), #155 (SaaS Container)

---

## Purpose

This playbook covers the **pre-launch warmup period** (Feb 28 - Mar 14) leading up to ADA's public launch on Mar 15. The goal is to build anticipation, seed content, and create a pipeline of early adopters ready to convert on launch day.

**Strategic context:** C1263 targets 10 paying customers ($100 MRR) by Mar 31. The funnel starts with 1,000 awareness → 200 install → 50 activate → 20 trial → 10 pay. This playbook focuses on **top-of-funnel awareness** before launch.

---

## Week 1: Foundation (Feb 28 - Mar 7)

### Day 1-2: Infrastructure Setup (Feb 28 - Mar 1)

**Channels:**

- [ ] **Discord server configured** (per C1224 spec)
  - Welcome channel with bot greeting
  - #announcements (locked, Growth + CEO only)
  - #general (open discussion)
  - #support (tech help)
  - #showcase (user wins)
  - Roles: Early Adopter, Beta Tester, ADA User
- [ ] **Twitter/X account active** (@ada_ai or similar)
  - Profile: bio, avatar, header image
  - Pinned tweet: "What is ADA?" explainer thread
- [ ] **Dev.to account created**
  - Profile connected to GitHub
- [ ] **Indie Hackers profile** (if not exists)

### Day 3-5: Content Seeding (Mar 2-4)

**Goal:** Plant 3-5 pieces of content that will mature by launch day.

| Platform      | Content Type                             | Status |
| ------------- | ---------------------------------------- | ------ |
| Twitter/X     | "Building ADA with ADA" thread (1/N)     | [ ]    |
| Dev.to        | "How We Built an Autonomous Dev Team" v1 | [ ]    |
| Reddit        | r/SideProject intro (soft, no promo)     | [ ]    |
| Indie Hackers | "Building in public" milestone post      | [ ]    |

**Content principles:**

- Lead with value, not product
- Share real numbers (cycles, tests, PRs)
- Be authentically indie/bootstrap
- No CTAs yet — just awareness

### Day 6-7: Community Warmup (Mar 5-7)

**Goal:** Begin engaging in relevant communities before we need them.

- [ ] Join 3-5 Discord servers where ADA users hang out (AI dev tools, indie hackers, side project communities)
- [ ] Comment thoughtfully on 5-10 relevant posts (add value, no links)
- [ ] Follow/engage with 20-30 dev influencers who might amplify launch
- [ ] Identify 3-5 potential beta testers for direct outreach

**Do NOT:**

- Drop links to ADA
- Pitch the product
- Ask for anything

**DO:**

- Be helpful
- Share insights
- Build familiarity

### Day 13: Early Adopter Pipeline (Mar 13)

**Goal:** Line up 20-30 people ready to try ADA on launch day.

- [ ] DM 10 developers who engaged with Week 1 content
- [ ] Post in Discord: "soft launch tomorrow — early adopter benefits"
- [ ] Email list tease (if exists): "Something's coming"
- [ ] Personal network outreach: 5-10 developer friends

**Early adopter offer:**

- First access (Mar 14 soft launch)
- Direct Discord support
- Input on roadmap
- Founding user badge/recognition

### Day 14: Soft Launch (Mar 14)

**Soft launch = limited release to early adopters before public blast.**

**Morning:**

- [ ] Billing system live (Engineering target)
- [ ] Pricing page live
- [ ] Signup flow tested end-to-end

**Afternoon:**

- [ ] Announce in Discord: "We're live for early adopters"
- [ ] DM early adopter list with signup link
- [ ] Monitor for signup issues
- [ ] Support first users through onboarding

**Evening:**

- [ ] Collect first user feedback
- [ ] Fix any blocking issues
- [ ] Prepare public launch materials for Mar 15

**Goal:** 5-10 signups on soft launch day. First paying customer if possible.

## Risk Mitigations

### Low Engagement Risk

**If Week 1 content gets <100 views:**

- Shift to more direct outreach (DMs, communities)
- Increase posting frequency
- Try different content formats (video, thread, long-form)

### Billing Not Ready Risk

**If billing slips past Mar 14:**

- Proceed with soft launch as free beta
- Collect emails for "launch pricing" notification
- Manual invoicing backup (per C1263)

### Discord Tumbleweed Risk

**If Discord stays empty:**

- Focus on Twitter/Reddit instead
- Convert to waitlist capture (per #200 contingency)
- Direct outreach for private beta group

## Publishing Checklist

- [ ] Fill in all template sections
- [ ] Include at least one code snippet or screenshot if possible
- [ ] Add memorable quote or insight for social
- [ ] Export key stats for Twitter thread
- [ ] Cross-post to: Twitter, Indie Hackers, Dev.to

## Content Derivatives

Each dev log should produce:

1. **Twitter Thread:** 5-8 tweets covering highlights + lesson + meta moment
2. **Indie Hackers Update:** Full dev log with community discussion prompt
3. **Newsletter Snippet:** 3-sentence summary for weekly digest
4. **LinkedIn Post:** Professional angle (team productivity, AI development)

## Tone Guidelines

- **Authentic:** We're not pretending this is magic — show the work
- **Specific:** Numbers, cycle counts, exact lessons — not vague progress
- **Meta-aware:** The fact that AI is building AI is inherently interesting
- **Developer-focused:** Speak to builders, not investors

### Quick Recap: What Is ADA?

If you missed our [first article](#), here's the TL;DR:

**ADA (Autonomous Dev Agents)** is an open-source framework for running AI development teams on any repository.

Instead of AI assistants that wait for your input, ADA agents:

- Check your issue backlog
- Pick the highest-priority task
- Write code with tests
- Open PRs
- Ship features

All while you sleep.

10 specialized roles (CEO, Engineering, QA, Product, Ops, Research, Design, Scrum, Frontier, Growth) rotate continuously, each with their own playbook defining their responsibilities.

### The Problem: Local-Only Limits Growth

ADA v1.0.0-alpha (shipped Feb 14) works great locally:

```bash
npm install -g @ada-ai/cli
ada init
ada dispatch start
```

But there's a catch: **you need to run it**.

Your laptop needs to stay on. Your terminal needs to stay open. Context is lost when you restart.

For individual developers? Fine.
For teams? A bottleneck.
For 24/7 autonomous operation? Not scalable.

---

### Sprint 3: The SaaS Sprint (Mar 1-14)

Sprint 3 changes everything. Here's what's shipping:

#### 1. GitHub OAuth Login

```bash
ada login
# Opens browser → GitHub OAuth → done
```

One command. Instant authentication. Your repos, your teams, your permissions.

#### 2. Stripe Billing Integration

Three pricing tiers:

| Tier       | Price  | Cycles/Day | Use Case                 |
| ---------- | ------ | ---------- | ------------------------ |
| Free       | $0     | 3          | Try it out               |
| Pro        | $49/mo | Unlimited  | Solo devs, side projects |
| Enterprise | Custom | Unlimited  | Teams, SLA, white-glove  |

Pro includes advanced analytics, priority support, and early access to new features.

#### 3. API Gateway

RESTful API for programmatic control:

```bash
# Trigger a dispatch remotely
curl -X POST https://api.ada.dev/v1/dispatch \
  -H "Authorization: Bearer $TOKEN" \
  -d '{"repo": "my-org/my-repo"}'
```

Integrate ADA into your existing workflows, CI/CD pipelines, or custom dashboards.

#### 4. Managed Execution

No local CLI needed. Run cycles from the web dashboard:

- Click "Run Dispatch"
- Watch agents work
- See results in real-time
- Memory persists across sessions

Your AI team never stops, even when you close your laptop.

### Pricing Philosophy

Why these prices?

**Free tier exists** because you shouldn't pay to discover. 3 cycles/day is enough to:

- Set up your first repo
- Run a few dispatches
- See if ADA fits your workflow

**Pro at $49/mo** is indie-friendly. Compare to:

- Copilot: $19/mo (assistant only)
- Cursor: $20/mo (assistant only)
- ADA Pro: $49/mo (full autonomous team)

  2.5x the price for 10x the capability? We think that's fair.

**Enterprise is custom** because every team is different. SLA, support, infrastructure requirements vary.

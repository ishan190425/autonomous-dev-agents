### Tweet 5 (How It Works)

Each "dispatch cycle":

1. Agent checks rotation → knows it's their turn
2. Reads memory bank → understands context
3. Checks GitHub → sees open issues/PRs
4. Picks ONE action from their playbook
5. Executes (code, docs, tests)
6. Updates memory → commits → next agent

Rinse, repeat. 24/7.

---

### Tweet 6 (Memory Bank)

The secret sauce: **shared memory**

Agents forget between sessions. So they write everything down:

- What's in progress
- Recent decisions
- Lessons learned
- Architecture context

Next agent reads this → instant context. No human needed.
